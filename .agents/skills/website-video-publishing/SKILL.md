# 官网视频发布

在 `dynamia-ai/website` 仓库操作。先读仓库根目录的 `AGENTS.md`，核对当前分支、未提交修改和已有视频 PR；属于同一批视频的修改沿用现有 PR。保留用户和其他人的改动。

## 素材与文案

- 中文视频链接必须有。英文视频链接可以暂缺；德语页使用英文视频，不需要单独提供德语链接。不要拿中文视频充当英文或德文视频。
- 用户通常会给中英文封面。按用户指定的对应关系使用原图；没有明确要求时，不自行生成、重绘或改写封面。缺少某语言封面时先说明实际展示效果，不把另一张带有不同语言文字的封面悄悄用于该语言。
- 标题、简介、时长优先使用用户提供的内容。未提供时，可根据可核实的视频内容和封面拟一版简短文案，在预览中注明是拟稿；不把推测写成事实，也不复制封面里与视频主题无关的文字。分别核对中英文时长，德文文案忠实翻译英文文案。
- 核对视频链接指向的实际视频、可播放状态及标题。链接无法访问或内容与所给素材对不上时，先处理这个问题，不用占位链接完成发布。

## 官网展示规则

- 中文页显示有中文链接的视频。只有中文链接时，英文和德文列表不显示该条，直接访问英文、德文详情也不能播放中文视频。
- 有英文链接时，英文和德文页播放同一个英文视频。两页文案分别为英文和德文；有各自封面时中文页用中文封面，英文和德文页用英文封面。
- 视频列表卡片按 16:9 展示。检查图片实际格式、尺寸、文字清晰度及裁切，尤其是标题和 Logo；不拉伸图片。比例不合适或关键内容被裁掉时，给用户看实际效果并请其提供替换图或确认处理方式。
- 修改现有视频时，只改用户指定的链接、封面或文案，不覆盖其他语言及已有内容。

## 文件与检查

- 视频条目在 `src/data/videos.ts`；列表和详情文案在 `dictionary/{zh,en,de}.json` 的 `videos.items`；封面放在 `public/images/videos/`。列表页是 `src/components/pages/VideosPage.tsx`，详情页是 `src/components/pages/VideoDetailPage.tsx`，详情路由在 `src/app/[locale]/videos/[videoId]/page.tsx`。
- 发布前检查仓库当前实现是否支持上述语言可见性和独立封面。若缺少能力，在本次视频相关改动中补齐并验证列表、详情和静态路由；不要仅把规则写进 Skill，却让网页继续错误展示。若已有实现位于另一待合并 PR，先确认依赖和合并顺序，避免重复修改。
- 预览 `/zh/videos`、`/en/videos`、`/de/videos` 及对应详情页，检查视频链接、文案、时长和封面在桌面及窄屏下的效果。缺英文视频时确认英文和德文都不出现该条。运行 `npm run lint` 与 `npm run build`。开发服务与生产构建不要同时写同一工作树的 `.next`；先停服务，或在独立工作树构建。
- 提交前核对 diff 只包含本次视频及必要的展示逻辑。不要改博客、活动、部署配置或无关视频。

## 提交与发布

- 用户说“先看”“本地预览”或“不要提交”时，做到本地预览和检查为止，不提交、不推送。明确要求上传或提交审核时，按博客的审核方式创建或更新 Ready PR，request `Shenhan11` 和 `spencercjh` review；不直接推送 `main`。
- 预览时给用户看拟写的简介、各语言实际展示的视频和封面，并说明缺失语言的处理。提交 PR 后提供链接、改动范围和检查结果。只有获得明确的合并上线授权，且仓库检查与所需 review 通过后，才合并并核对官网结果。
