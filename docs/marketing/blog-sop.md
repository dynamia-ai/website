# 市场同事：新增和修改官网博客

本流程供公司内部同事使用。新增文章：复制企业飞书中的正式模板写稿，把链接交给 Agent。修改文章：直接把官网链接和修改要求发给 Agent，也可以附上新图片。Agent 生成预览和待审核 PR，网站维护者审核后发布；无需先改飞书才能修改官网。

## 第一次使用

准备自己的 GitHub 账号、公司飞书账号和公司允许使用的 Agent。GitHub 账号需由公司授权创建内容分支和 PR，不需要管理员权限或生产密钥。Agent 必须能读写项目、运行命令和 Git，并提供浏览器或人工预览入口；并非所有聊天工具都能完成。

将下面这段话交给自己的 Agent：

> 请帮我配置公司官网博客编辑环境，仓库是 https://github.com/dynamia-ai/website ，企业发布入口是【粘贴公司飞书《官网博客发布》链接】。先读 AGENTS.md，再按 .agents/skills/website-blog-from-feishu/SKILL.md 的“首次配置”入口检查。配置官方 Lark CLI 和配套 Skills，使用公司批准的应用，由我本人授权，并验证能读取企业 SOP、正式模板、官网文章库和稿件图片。若主分支还没有这个流程，可先准备账号和工具，并告诉我联系维护者。需要我本人登录时给我入口，最后说明什么已就绪、还缺什么；此次不发布内容。

登录和组织邀请由本人完成，不把密码或 token 发给 Agent。其他安装、检查、拉取和预览都可由 Agent 操作。云端 Agent 要在它实际执行的环境里配置，本机登录不等于云端已登录。

Skill 随仓库维护一份，不保证每个 Agent 都自动发现。支持自动发现的工具可以加载 `website-blog-from-feishu`，其他工具使用下面的完整路径指令即可。

## 新增一篇文章

1. 从企业飞书的《官网博客发布》入口取得正式模板，创建副本并放入官网文章库，把**文档名称改成文章标题**。[仓库模板说明](feishu-blog-template.md)仅供核对结构，日常稿件统一使用企业飞书母版。
2. 在“正文”下面写文章。作者已预填公司名，特殊署名才修改该行。封面可插入一张图片，留空就使用网站文字封面。正文中的图片照常插在对应段落之间。“正文”之后的全部内容都会用于发稿，内部讨论放评论。
3. 把链接和发稿要求交给 Agent：

> 请先读取仓库 AGENTS.md 和 .agents/skills/website-blog-from-feishu/SKILL.md，将这篇飞书稿件新增为官网博客：[文档链接]。保留原文措辞和图文顺序，生成预览并提交待审核 PR，不要合并上线。

摘要、日期、语言、分类、标签和网址短名都由 Agent 处理，不需要填表。摘要根据正文生成，Agent 返回预览时会单独列出并提醒你看一眼；想强调什么、删哪一句，直接聊天反馈即可调整。日期默认当天，语言根据原文判断；有特别要求直接说明。当前支持中文和英文，不会自动翻译。仅想查看效果时明确说“只做本地预览，不提交 PR”。

模板作者预填“密瓜智能”，英文稿由 Agent 默认使用“Dynamia”；特殊署名可直接修改作者行，也可在聊天中要求保留某种写法。真实署名和转载原作者会保留。它用于搜索/分享元信息，当前正文页不显示，Agent 会在预览说明中列出实际值，并提醒页面暂不展示署名。修改已有文章时，未要求更改作者就保持原样。

封面建议用 1600 × 900 像素的 16:9 横图，格式 JPG、PNG 或 WebP，建议控制在 2 MiB 内，单图不能超过 10 MiB。官网会居中裁切，关键文字、Logo 和人物不要贴边或放在右上角分类标签下面。其他尺寸也可交给 Agent 检查，有明显模糊或裁掉重要内容时再换图。

## 修改已有文章

发官网链接，直接说怎么改，不必打开或同步飞书稿。图片可以直接上传聊天：

> 请先读取仓库 AGENTS.md 和 .agents/skills/website-blog-from-feishu/SKILL.md，修改这篇官网文章：[官网链接]。把“原句”改成“新句”，标题改成“新标题”，封面换成我上传的图片。其余内容和网址保持原样，生成预览和待审核 PR。

也可以只提出其中一项，或说“把某段后面的正文图换成附件”。Agent 能唯一定位就直接做；出现多处相同文字或图的位置不明确时才会问。文章标题与单独设置的封面标题可能不同，Agent 会在预览中说明；改正文图不会顺带改封面。

修改以官网仓库或当前待审版本为准，不自动回写飞书，也不要求你维护两份。之后再把旧飞书稿交给 Agent 时，说明本次希望修改什么；它会保留已经在聊天中完成的修改。确实要重写整篇时，明确说“用这份稿件整篇重写”。

## 查看结果

打开预览，看一眼 Agent 生成的摘要，再检查标题、封面裁切、段落、图片、表格、链接和手机效果；修改意见直接在聊天中提出。文档的图文顺序会保留，网页不逐像素复制飞书排版。发稿或官网改稿要求表示将指定内容提交公开审核；如果稿件仍含内部或未公开说明，Agent 会先集中确认冲突。

| 返回状态 | 含义 |
| --- | --- |
| 本地草稿 / 本地预览 | 尚未上传公开审核，可能仍有缺图或检查问题 |
| 待审核 PR | 一次有记录的修改申请，尚未上线 |
| 预览可用 | 可以看网页效果，托管预览可能公开 |
| 已合并 | 维护者已接受修改，仍需检查生产部署 |
| 已上线并验证 | 真实官网的列表、文章和图片已核验 |

看不到飞书稿时确认本人账号有访问权限；缺图时可直接上传图片。检查失败让 Agent 报告原因并保留修改，交维护者处理。不要让它删除检查、改网站代码或直接覆盖主分支。

维护者审核后合并并验证真实官网；需要撤回时请维护者创建回退 PR。飞书修改不会自动上线，本流程也不负责定时发布、任意附件下载页或自定义页面功能。
